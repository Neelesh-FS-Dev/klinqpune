# KLINQ — Cocktails & Cuisine: concept website

Independent creative concept by Codevirel Studio. Not commissioned, approved or launched by KLINQ.

## Run it
```bash
npm install
npm run dev          # local development
npm run build        # typecheck and production build
npm run preview      # serves the build on http://localhost:4790
npm test             # unit tests for event status logic
npx playwright install chromium   # once, for browser tests
npm run e2e          # browser suite (builds and previews first)
```

## Layout
- `src/` — React + TypeScript app. Data in `src/data/`, motion in `src/motion/`, styles in `src/styles/`.
- `public/media/` — optimised WebP photos and MP4 loops, generated by `scripts/optimize-media.py`.
- `public/brand/` — logo lockup (cropped from the supplied poster; replace with the official file).
- `assets/instagram/` — original supplied media. Ignored by git. Not for republication.
- `docs/` — research, design, media, motion, events, performance and QA reports.
- `e2e/` — Playwright functional, accessibility and screenshot tests.

## Routes
`/` home · `/experience` · `/menu` (also `/food` and `/drinks`) · `/events` · `/faces` · `/celebrate` · `/gallery` · `/visit`
