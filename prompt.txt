# 26. LIQUID MOTION TECHNIQUE

Do not attempt real-time fluid simulation unless a strong technical reason exists.

Preferred approaches:

Authentic slow-motion pour footage.

Optimized pre-rendered liquid animation.

Canvas image sequence.

Layered video or photographic masks.

Select the technique with the best visual fidelity.

For image sequences:

- Load critical frames first.
- Limit concurrent requests.
- Use bounded memory.
- Decode progressively.
- Avoid full-resolution frame loading on mobile.
- Draw only necessary frames.
- Provide static fallbacks.

For video scrubbing:

- Inspect keyframe intervals.
- Test Safari seeking.
- Use optimized encoding.
- Avoid redundant seek operations.
- Preserve poster imagery.

For WebGL:

- Animate stable object properties.
- Avoid frame-by-frame React state.
- Use refs for animation progress.
- Implement rendering cleanup.

Do not combine all expensive techniques in one scene.
